최종 아이콘: NotesPlus-blue-exact.png / ../AppIcon.icns
색상: 앱의 NSColor.controlAccentColor와 같은 sRGB #007AFF.
원본: 설치된 /System/Applications/Notes.app의 NSWorkspace 아이콘 이미지 표현.
방식: 사용자 명시 승인 후 원본의 노란 헤더 픽셀만 HSV 기반 파란색으로 치환.
투명도, 치수, 윤곽, 제본 구멍과 흰 본문/선은 원본 그대로 보존.
16~1024px의 7개 원본 크기를 검증. ICNS는 8개 무손실 PNG 표현을 포함하며 작은 크기는 Retina PNG를 사용.
검증: ../../build/icon-verification.json, ../../build/icon-comparison.png

이전에 내장 imagegen으로 만든 회색 및 파란색 시안은 원본과 형태 차이가 있어 최종 결과에서 제외했습니다.
시안 프롬프트 요약: 원본 메모 아이콘에서 노란 헤더만 회색/시스템 파란색으로 변경하고 형태·종이·구멍·선을 보존, 투명 배경.
최종 결과에는 생성형 이미지나 CLI 이미지 생성 API를 사용하지 않았습니다.
