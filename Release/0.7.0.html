NotesPlus 0.7.0

앱 안에서 업데이트

  • 설정 하단과 앱 정보에서 현재 버전과 빌드 번호를 확인합니다.
  • NotesPlus 메뉴의 ‘업데이트 확인…’에서 새 버전의 변경 내용을 확인하고 설치합니다.
  • 하루에 한 번 새 버전 소식을 확인하며 설정에서 끌 수 있습니다. 설치는 사용자가 선택한 뒤 진행합니다.
  • 업데이트 파일과 소식의 서명을 검증한 뒤 앱을 교체합니다. 메모·초안·설정은 유지됩니다.

저장과 충돌 처리 개선

  • 저장 확인이 늦거나 이전에 저장한 버전이 다시 도착할 때 작성 중인 본문을 유지합니다.
  • 서식·본문을 읽는 사이 메모가 변경되면 전체 내용을 다시 확인합니다.
  • 실제 충돌은 ‘두 버전 확인’에서 비교하고 선택합니다. 선택 전에 양쪽 버전을 Mac에 보관합니다.
  • 최근 저장 기록과 서식만 변경한 초안도 재실행 후 복구합니다.

체크리스트·표·첨부·복잡한 서식의 직접 편집은 아직 지원하지 않습니다. 이번 버전은 네이티브 기능 전체를 구현한 버전이 아닙니다.

Developer ID 서명 및 Apple 공증 없이 제공하는 시험 배포입니다.
