NotesPlus 0.6.0 — 첫 시험 배포

Apple Silicon Mac / macOS 26 이상을 지원합니다.
이번 배포는 Developer ID 인증서와 Apple 공증 없이 제공하는 Pre-release입니다.

설치
1. 아래 NotesPlus-0.6.0-macOS-arm64.dmg를 내려받습니다.
2. DMG를 열어 NotesPlus.app을 Applications 폴더로 옮긴 뒤 실행합니다.
3. 첫 연결 때 기본 메모에 대한 자동화 권한을 허용합니다.

첫 실행 보안 경고
개발자를 확인할 수 없거나 Apple이 앱을 확인할 수 없다는 경고가 나오면, 이 저장소에서 받은 파일인지 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안 → NotesPlus의 ‘그래도 열기’ → ‘열기’를 선택합니다. 요청되면 Mac 암호 또는 Touch ID로 확인합니다.
‘컴퓨터를 손상시킵니다’나 ‘앱이 손상되었습니다’라는 경고는 위 절차로 진행하지 말고 다시 다운로드해 체크섬을 확인하거나 Issues에 알려 주세요.
상세 설치 안내: https://github.com/Recrude/NotesPlus/blob/main/Release/READ-ME.txt
Apple 안내: https://support.apple.com/ko-kr/102445

주요 기능
- 한글 행간, 서체, 여백과 입력 동작을 세부 설정.
- 입력 중 약 8초 단위, 입력이 멈추면 1.2초 뒤 자동 저장.
- 실제 번호 목록과 iPhone 기본 메모에서의 이어쓰기. 별표는 그대로 유지.
- ⌘⌃T 타임스탬프 삽입. 날짜 형식과 단축키 변경 가능.
- 생성일 기준 최신 먼저 정렬.

현재 제한
글머리·체크리스트, 복잡한 서식, 첨부·표, 공유·잠긴 메모는 읽기 전용입니다.
두 기기의 동시 편집은 자동 병합하지 않습니다. Apple의 공식 앱이 아닙니다.

검증
자동 검사 107개 통과. 실제 Mac/iPhone에서 번호 목록 양방향 반영, 타임스탬프 삽입과 기본 메모 저장을 확인했습니다.
DMG 내부에 설치 안내를 포함했고 다운로드 파일의 SHA-256 체크섬을 함께 제공합니다.
