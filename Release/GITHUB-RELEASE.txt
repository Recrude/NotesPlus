NotesPlus 0.8.0-beta.2 — 이미지·복합 서식 메모의 본문 편집

이미지와 추가 서식이 있는 메모도 NotesPlus에서 본문을 계속 작성할 수 있습니다. 원본 첨부 참조와 색상·강조·사용자 서체·크기·정렬 데이터를 유지합니다. 복합 서식 표는 표 영역만 보호하며, 변경하지 않은 표를 다시 업로드하지 않습니다.

새 편집기 식별자를 문서 이력의 올바른 순서에 등록하도록 수정했습니다. 이전 처리는 일부 기존 메모를 기본 앱에서 병합할 때 본문을 중복시킬 수 있었습니다. 이미 중복된 메모를 자동 삭제하거나 재작성하지는 않습니다.

입력과 저장은 계속 분리됩니다. 이미지 미리보기는 비동기로 내려받고 별도 작업에서 디코딩하며, 원본 서식이나 첨부 보존 검사에 실패하면 업로드를 중단하고 초안을 유지합니다.

검증
- TypeScript 83개, 네이티브 편집·동기화·입력·서식 왕복 테스트 통과.
- 별도 테스트 메모에서 Mac Notes → NotesPlus → iPhone 왕복 확인: 이미지, 강조, 링크, 목록, 체크 상태, 표와 본문 유지.
- iPhone 체크 변경을 받은 뒤 NotesPlus에서 계속 작성한 내용이 iPhone에 반영됨.
- 기존 개인 메모는 검증 과정에서 수정하지 않음.

현재 범위
기존 첨부의 앞뒤 본문을 편집합니다. 새 이미지 첨부·교체·삭제·이동과 복합 표 영역 편집은 아직 제한됩니다. 복합 표 미리보기가 원본의 모든 서식을 표시하지는 않습니다. 잠금·공유·대용량 본문 및 해석할 수 없는 문서 이력은 계속 보호합니다.

설치와 업데이트
0.8 베타 사용자는 NotesPlus → 업데이트 확인…에서 앱만 교체할 수 있습니다. DMG로 설치하려면 앱을 종료하고 Applications의 NotesPlus.app을 교체합니다. 기존 초안과 설정은 유지합니다.
Apple Silicon / macOS 26 이상. Developer ID 서명·Apple 공증 없이 제공하는 베타입니다. 첫 실행 보안 경고는 시스템 설정 → 개인정보 보호 및 보안 → NotesPlus의 ‘그래도 열기’에서 확인합니다. SIP를 해제할 필요는 없습니다.
