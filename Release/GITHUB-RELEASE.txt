NotesPlus 0.7.0 — 앱 내 업데이트와 저장 안정성 개선

Apple Silicon Mac / macOS 26 이상. Developer ID 인증서·Apple 공증 없이 제공하는 시험 배포입니다.

변경 사항
- 설정 하단과 앱 정보에 현재 버전·빌드 번호 표시.
- NotesPlus 메뉴 → 업데이트 확인…에서 새 버전 소식과 변경 내용을 읽고 설치.
- 하루 한 번 새 버전 자동 확인, 설정에서 해제 가능. 설치는 사용자가 선택한 뒤 진행.
- 서명된 업데이트 파일과 피드 검증 후 앱 교체·재실행. 메모·초안·설정 유지.
- 저장 확인 지연과 이전 저장본 재등장으로 인한 잘못된 충돌 처리 보강.
- 두 버전 비교·선택과 선택 전 양쪽 보관. 최근 저장 기록·서식 변경 초안 복구 개선.

0.6 사용자
0.6에는 업데이트 기능이 없으므로 이번에는 앱을 종료하고 0.7 앱으로 한 번 덮어써 주세요. 삭제는 필요 없습니다. 이후부터 앱 내 업데이트를 사용합니다.

설치
DMG를 열고 NotesPlus.app을 Applications 폴더로 옮긴 뒤 실행합니다. 첫 연결 시 기본 메모 자동화 권한을 허용합니다.
첫 실행에서 확인되지 않은 개발자 등의 경고가 나오면 공식 저장소에서 받은 파일인지 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안 → NotesPlus의 ‘그래도 열기’ → ‘열기’를 선택합니다.
‘컴퓨터를 손상시킵니다’ 또는 ‘앱이 손상되었습니다’라는 경고는 위 절차로 진행하지 말고 재다운로드·체크섬 확인 후 Issues에 알려 주세요.
설치 안내: https://github.com/Recrude/NotesPlus/blob/main/Release/READ-ME.txt
Apple 안내: https://support.apple.com/ko-kr/102445

현재 제한
체크리스트·표·첨부·복잡한 서식·공유·잠긴 메모는 읽기 전용입니다. 기본 메모의 모든 기능을 구현한 버전은 아닙니다. 공개 자동화 API로 연결하므로 두 기기의 완전히 동시적인 편집을 원자적으로 병합·저장하지는 못합니다.

검증
자동 검사 141개 통과. 격리된 테스트 앱에서 실제 다운로드·설치·재실행, 종료 취소, 미저장 초안 전체와 설정 보존, 최신 버전 감지를 확인했습니다. ZIP·피드 변조 시 서명 검증 실패도 확인했습니다.
