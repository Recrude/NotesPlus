NotesPlus 0.8 베타 1

체크리스트·글머리·표를 NotesPlus 안에서 편집하고 iCloud에 구조를 보존해 저장하는 새 편집기를 통합했습니다.

  • 기존 개인 iCloud 폴더, 실제 체크 상태, 번호 목록, 표 삽입과 기본 행·열 편집.
  • 입력과 저장 분리, 한글 조합 보호, 메모별 저장 상태, 원본 백업과 일시적인 버전 충돌 재시도.
  • 기존 설정, 타임스탬프, 생성일 정렬, 베타 채널 업데이트 통합.

0.7에서 처음 전환할 때 Apple 페이지에서 iCloud 연결이 필요합니다. 잠금·공유·이미지 첨부·지원하지 않는 복합 서식 등은 편집하지 않습니다. 표 전체 이동·삭제와 표 셀의 인라인 서식 변경은 미지원입니다.

Developer ID 서명 및 Apple 공증 없음. 설치 방법과 범위는 DMG의 READ-ME.txt를 확인하세요.
