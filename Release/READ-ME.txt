NotesPlus 0.8.0-beta.1 (801)
Apple Silicon Mac / macOS 26 이상

설치와 연결
1. 기존 NotesPlus를 종료해 작성 내용을 저장한 뒤, DMG의 NotesPlus.app을 Applications 폴더로 옮겨 기존 앱을 교체합니다. 앱을 삭제할 필요는 없습니다.
2. NotesPlus에서 ‘iCloud 연결’을 누르고 Apple의 로그인 페이지에서 직접 로그인과 2단계 인증을 완료합니다. 이후 ‘로그인 완료 · 연결’을 누릅니다.
3. 저장된 연결 정보를 사용할 때 macOS 키체인이 Mac 로그인 암호를 요청할 수 있습니다.
기존 표시·입력 설정은 유지됩니다. 0.7의 자동화 연결 대신 iCloud에 직접 연결하므로 첫 연결은 별도로 필요합니다.

첫 실행 보안 경고
Developer ID 서명과 Apple 공증을 받지 않은 베타입니다. Recrude/NotesPlus의 GitHub Releases에서 받은 파일인지 확인하세요.
앱을 한 번 실행한 뒤 확인되지 않은 개발자 또는 Apple이 확인할 수 없다는 경고가 나오면, 시스템 설정 → 개인정보 보호 및 보안 → NotesPlus의 ‘그래도 열기’ → ‘열기’를 선택합니다. 요청되면 Mac 암호 또는 Touch ID로 확인합니다.
시스템 전체 보안 설정이나 SIP를 끌 필요는 없습니다.
‘컴퓨터를 손상시킵니다’ 또는 ‘앱이 손상되었습니다’라는 경고는 위 절차로 진행하지 말고 다운로드 파일의 체크섬을 확인하거나 Issues에 알려 주세요.

편집
입력과 네트워크 저장을 분리합니다. 잠시 멈추면 기본 1.2초 뒤, 연속 입력 중에도 주기적으로 저장합니다. 한글 조합이 끝나기 전에는 저장용 문서로 변환하지 않습니다.
체크리스트, 글머리·번호 목록, 기본 인라인 서식, 표 삽입·셀 편집·행/열 추가·삭제를 NotesPlus 안에서 처리합니다.
표 구조 변경은 앞선 입력이 저장된 뒤 실행합니다. 저장 중 다른 곳을 편집하거나 커서를 옮겼다면 작업을 다시 선택하라는 안내가 표시될 수 있습니다.
1. / 1) 뒤에 공백을 입력하면 실제 번호 목록을 만들며 Return으로 이어집니다. *는 기본값에서 그대로 유지됩니다. 설정에서 각 기호의 자동 변환을 따로 바꿀 수 있습니다.
⌘⌃T: 현재 커서 위치에 타임스탬프 삽입. 기본 yyyy/MM/dd HH:mm, 설정에서 yyyyMMdd HHmmss 등 형식과 단축키 변경.
기본 정렬은 생성일입니다. 행간·글꼴·여백 등 표시 설정은 이 Mac의 NotesPlus에만 적용합니다.

기존 메모와 보호 범위
기존 개인 iCloud 폴더를 불러옵니다. Gmail·‘나의 Mac’ 계정, 다른 사람이 공유한 별도 영역, 잠긴 메모 편집은 지원하지 않습니다.
이미지·스캔 등 표 이외의 첨부, 색상·강조·사용자 서체 등 아직 온전히 표현하지 못하는 서식, 복합 서식이 있는 표 셀, 별도 파일에 저장된 대용량 메모는 원본 보존을 위해 읽기 전용입니다. 읽기 전용 화면의 본문은 텍스트 미리보기입니다.
표 전체의 이동·삭제와 표 셀 내부의 굵게·기울임 등 서식 변경은 아직 지원하지 않습니다. 표 구조가 서로 다른 방식으로 동시에 변경되면 자동 저장을 거부하고 초안을 보관합니다.
서식 보존 검사에 실패한 메모를 일반 텍스트로 덮어쓰지 않습니다.

충돌과 복원
독립적인 문단·셀 변경은 자동으로 합칩니다. 같은 부분을 양쪽에서 바꾼 경우에는 전체 작성본을 유지하고 ‘두 버전 확인’에서 선택합니다. 선택 전에 양쪽을 로컬에 보관합니다.
미저장 초안, 저장 전 원본 구조, 충돌 사본: ~/Library/Application Support/NotesPlus/Structured/
설정 → 저장 → 보관 폴더 열기에서 접근할 수 있습니다. 앱 교체로 삭제되지 않으며, 로컬 사본은 로그인 사용자만 읽을 수 있는 파일 권한으로 저장합니다. 별도 암호화나 자동 정리는 없습니다.
0.7의 미저장 초안과 실험판 초안은 기존 보관 위치에 그대로 남습니다. 이 베타가 기존 초안을 자동 변환하거나 iCloud 원본 위에 덮어쓰지 않습니다.

업데이트
설정 하단과 앱 정보에서 버전·빌드를 확인합니다. NotesPlus 메뉴 → 업데이트 확인…에서 베타 채널의 새 버전을 확인하고 앱을 교체할 수 있습니다.
0.7 안정 채널에는 이 베타를 자동 배포하지 않습니다. 0.8 베타로 옮기는 첫 설치는 이 DMG로 앱을 교체합니다. 이후 베타 업데이트는 앱 안에서 진행합니다.
다운로드와 업데이트 소식은 기존 Ed25519 키로 서명합니다. 이는 Apple 공증과 별개입니다.

연결 방식과 한계
웹 편집기를 끼워 넣지 않은 네이티브 AppKit 편집기입니다. Apple의 비공개 Notes 문서 형식과 iCloud 연결을 이용하며 Apple의 공식 제품이나 공식 Notes API 클라이언트는 아닙니다.
Apple의 로그인 정보는 로컬 키체인에 저장하고 메모와 함께 Apple iCloud에만 전송합니다. 별도 운영 서버는 없습니다.
Apple의 형식·인증 정책 변경, 연결 상태 등에 따라 동기화가 지연되거나 다시 로그인이 필요할 수 있습니다. 기기 간 반영 시간은 보장하지 않습니다.
