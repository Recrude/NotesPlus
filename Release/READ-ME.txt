NotesPlus 0.7.0
Apple Silicon Mac / macOS 26 이상

설치
NotesPlus.app을 Applications 폴더로 옮깁니다.
기존 버전을 사용 중이면 먼저 종료하여 변경 내용을 저장합니다.
첫 연결 때 NotesPlus가 기본 메모에 접근할 수 있도록 자동화 권한을 허용합니다.
iCloud 메모는 Mac 기본 메모에서 같은 Apple 계정으로 먼저 연결되어 있어야 합니다.

첫 실행 시 보안 경고가 나오는 경우
이 배포본은 Developer ID 인증서와 Apple 공증을 사용하지 않은 시험 버전입니다.
Recrude/NotesPlus의 GitHub Releases에서 받은 파일인지 확인한 뒤 진행합니다.
1. 응용 프로그램 폴더에 복사한 NotesPlus를 한 번 실행합니다. 확인되지 않은 개발자 또는 Apple이 확인할 수 없다는 경고가 나오면 닫습니다.
2. 시스템 설정 → 개인정보 보호 및 보안을 열고 아래쪽 보안 항목에서 NotesPlus의 ‘그래도 열기’를 누릅니다.
3. 다시 표시되는 확인 창에서 ‘열기’를 선택하고, 요청되면 Mac의 암호 또는 Touch ID로 인증합니다.
4. 이후에는 응용 프로그램 폴더에서 평소처럼 실행할 수 있습니다.
‘그래도 열기’가 없으면 앱을 다시 실행한 뒤 확인합니다. 조직에서 관리하는 Mac에서는 관리자 정책으로 제한될 수 있습니다.
‘컴퓨터를 손상시킵니다’ 또는 ‘앱이 손상되었습니다’라는 경고는 위 절차로 진행하지 말고, 파일을 다시 내려받아 체크섬을 확인하거나 Issues에 알려 주세요.
Apple 안내: https://support.apple.com/ko-kr/102445
다운로드: https://github.com/Recrude/NotesPlus/releases/tag/v0.7.0
문의: https://github.com/Recrude/NotesPlus/issues

업데이트
설정 하단에 현재 버전과 빌드 번호가 표시됩니다.
NotesPlus 메뉴 → 업데이트 확인…에서 새 버전의 변경 내용을 확인하고 설치합니다.
업데이트 파일과 소식의 서명을 검증한 뒤 앱만 교체하고 재실행합니다. 삭제 후 재설치는 필요 없습니다.
하루에 한 번 새 버전 소식을 확인하며 설정 → 업데이트에서 끌 수 있습니다. 설치는 사용자가 선택합니다.
0.6에는 업데이트 기능이 없으므로 이번 0.7만 앱을 종료하고 파일을 덮어씁니다. 이후부터 앱 내 업데이트를 이용합니다.

사용
입력하면 자동으로 저장합니다. 잠시 멈추면 1.2초 뒤, 계속 입력하면 약 8초 간격입니다.
⌘⌃T: 현재 커서 위치에 날짜·시간 삽입. 기본 형식 yyyy/MM/dd HH:mm.
⌘, → 시간: 날짜 형식과 단축키 변경. yyyyMMdd HHmmss 형식도 선택할 수 있습니다.
메모는 기본적으로 생성일 기준, 최근에 만든 메모부터 표시합니다.
1. 뒤에 공백을 입력하면 실제 번호 목록을 만들며 Return으로 번호가 이어집니다.
* 뒤에 공백을 입력해도 그대로 유지합니다.
글꼴과 행간은 NotesPlus의 표시 설정이며 다른 기기의 표시 설정은 바꾸지 않습니다.

데이터
Mac 기본 메모를 통해 기존 메모를 읽고 저장합니다. iCloud 동기화는 Apple 메모가 담당합니다.
별도 Apple 계정 암호, 별도 클라우드 저장소 또는 메모 데이터베이스 패치는 사용하지 않습니다.
네트워크가 끊기면 기기 간 반영은 다시 연결된 뒤 진행됩니다.
미저장 초안과 저장 전 백업: ~/Library/Application Support/NotesPlus/
앱 교체 시 이 폴더와 기존 설정은 유지됩니다. 이 로컬 사본에는 별도 암호화/자동 정리 기능이 없습니다.

현재 지원 범위
일반 텍스트·단순 제목·번호 목록을 편집합니다.
글머리/체크리스트, 복잡한 서식, 표/첨부, 공유/잠긴 메모는 보존을 위해 읽기 전용입니다.
두 기기의 동시 편집을 자동 병합하지 않습니다. 충돌 시 현재 본문을 유지하고 두 버전을 비교·선택합니다. 선택 전에 양쪽을 Recovered 폴더에 보관합니다.
Apple Notes의 모든 기능과 동일한 앱은 아닙니다. Apple의 공식 제품이 아닙니다.
