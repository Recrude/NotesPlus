NotesPlus 0.6 설정 범위

설정창: ⌘, / 모두 펼친 7개 그룹 + Apple 관리 안내
글머리·체크리스트 관련 항목은 현재 지원 제한을 표시하며 비활성화됩니다.
이전 사용자의 행간 등 설정을 보존하며, 아래 기본값은 새 설치와 초기화에 적용됩니다.

기본 (7)
정렬 기준: 생성일 [생성일/수정일/제목]
정렬 방향: 최신 먼저 [오래된 먼저 또는 가나다순/역순]
날짜 그룹화: 켬 (제목 정렬 때 일시 비활성)
보기: 목록 [목록/갤러리]
새 메모 첫 줄: 본문 [제목/머리말/부제목/본문]
새 메모 위치: 현재 선택한 폴더 [사용 가능한 계정/폴더]
다크 본문: 켬

서체·여백 (10)
글꼴: 시스템 기본 [설치된 글꼴]
굵기: 보통 [보통/중간/굵게; 글꼴이 지원하는 굵기에 따라 적용]
기본 크기: 15pt [10–40]
행간 배율: 1.6 [1.0–3.0]
문단 뒤 간격: 0pt [0–40]
자간: 0pt [-1–5]
좌우 여백: 20pt [8–100]
상하 여백: 5pt [0–80]
본문 너비 제한: 끔 [켬일 때 320–1200pt]
탭 너비: 4칸 [2/4/8]

목록
1. + 공백으로 실제 번호 목록 시작: 켬
1) + 공백으로 실제 번호 목록 시작: 켬 (표시는 기본 번호 목록의 마침표 형식)
실제 번호 목록은 Return으로 다음 항목을 이어 작성합니다.
* / - / + 뒤 공백: 문자 그대로 유지. 자동 글머리 변환과 기호 선택/이어쓰기는 비활성.
빈 항목에서 Return으로 종료: 켬
새 줄 들여쓰기 유지: 켬
Tab으로 공백 입력: 끔
빠른 조합: 번호만 자동 / 모두 직접 입력
직접 입력 명령에만 적용. 붙여넣기와 한글 IME 조합은 변환하지 않음.
번호 목록은 실제 ol/li로 저장하며 iPhone에서도 목록으로 편집할 수 있습니다.
글머리·체크리스트는 공개 API에서 체크 상태를 구분할 수 없어 기본 메모에서 편집합니다.
이전 설정의 글머리 관련 값은 파일 호환성을 위해 보존하지만 현재 동작에는 적용하지 않습니다.

입력 (8)
맞춤법 검사: 켬
문법 검사: 끔 (맞춤법 검사와 함께 사용)
맞춤법 자동 수정: 끔
스마트 따옴표: 끔
스마트 대시: 끔
macOS 텍스트 대치: 켬
인라인 텍스트 완성: 끔
잘라내기/붙여넣기 스마트 공백: 켬
검사 언어와 텍스트 대치 사전은 macOS를 따름.

시간 · 타임스탬프 (3)
형식: yyyy/MM/dd HH:mm [직접 편집, 최대 120자, 한 줄]
빠른 선택: yyyy/MM/dd HH:mm / yyyyMMdd HHmmss
보조 키: ⌃⌘ [⌥⌘/⇧⌘/⌃⇧⌘/⌥⇧⌘/⌃⌥⌘/⌃⌥⇧⌘]
키: T [A–Z/0–9]
주요 편집/시스템 단축키와 겹치는 일부 조합은 기본 ⌃⌘T로 복원합니다.
본문의 커서 또는 선택 영역에 현재 Mac의 날짜·시간을 삽입합니다. 시간대는 현재 Mac 설정을 따릅니다.
yyyy: 연도 / MM: 월 / dd: 일 / HH: 24시간 / mm: 분 / ss: 초. 대소문자를 구별합니다.
입력한 타임스탬프는 고정된 문자열이며 시간이 지나도 자동 갱신되지 않습니다.
일반 입력과 같이 자동 저장/실행 취소를 지원합니다. 한글 조합 중·읽기 전용 메모에서는 삽입하지 않습니다.
이 그룹의 초기화는 다른 설정을 변경하지 않습니다.

화면 (13)
테마: 시스템 [시스템/라이트/다크]
본문 수정 날짜: 켬
본문 글자 수: 끔
폴더 개수: 켬
미리보기: 1줄 [숨김/1/2/3]
목록 간격: 보통 [좁게/보통/넓게]
목록 제목 크기: 14pt [11–20]
검색 범위: 제목+불러온 미리보기 [제목만/제목+미리보기]
서식/체크리스트/표/첨부파일/텍스트 사본 공유 도구: 각각 켬 (5개)
앞의 4개 도구는 기본 메모의 해당 메모를 엶. 공유는 공동 편집 초대가 아닌 텍스트 사본.

저장 (4)
입력이 멈춘 뒤 저장 대기: 1.2초 [0.3–3]
연속 입력 중 저장 간격: 8초 [3–30]
원본 변경 확인: 3초 [2–30]
마지막 메모 다시 열기: 켬
자동 저장 자체는 항상 켬. 이동/종료 시 남은 변경을 저장하며 백업/충돌 보호는 유지.
입력은 저장과 분리하며 한글 조합이 끝날 때까지 저장을 미룹니다. 저장 중의 새 입력은 다음 저장에 포함됩니다.
원본 변경 확인 주기로 현재 폴더의 새 메모도 확인하고, 앱 활성화 때 목록을 갱신합니다.
iCloud의 전송 속도나 서버 저장 완료를 제어하는 옵션이 아님.

Apple 기본 메모에서 관리하는 원래 옵션
기본 계정(Siri), 나의 Mac 계정 활성화, 마지막 빠른 메모 재개,
완료한 체크리스트 항목 자동 정렬, 멘션 알림,
잠긴 메모 암호 설정/변경/재설정, Touch ID.
기본 메모 열기 버튼 + ⌘, 안내 + Apple 공식 도움말 링크를 제공.
시스템 링크/하이라이트 색상도 macOS 관리 위치 안내.
NotesPlus가 이 값을 읽거나 쓴 것처럼 표시하지 않음.

설정 파일
우측 상단 더 보기: JSON 내보내기/불러오기, 전체 복원.
가져오기 실패 시 기존 값은 변경하지 않음. 숫자 범위는 검증하며 알 수 없는 키는 거부.
지원 버전보다 새로운 설정 파일의 알 수 없는 키는 자동으로 무시하지 않음.
기본 폴더 ID는 Mac의 메모 연결에 종속됨. 다른 Mac에서 불러온 뒤 다시 선택해야 할 수 있음.
